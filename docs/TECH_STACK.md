- **OS**: Ubuntu 24.04（Linux 6.14.0-35-generic）

- **言語**: Python 3.12.3
- **パッケージ管理**: uv

## 環境構築手順

未整備。フェーズ1（環境構築案件）で uv によるプロジェクト初期化（`uv init` / `uv add`）を行い、確定したセットアップコマンド（`uv sync` 等）を本節に記載する。

導入予定（2026-08-05 の事前検証で動作確認済み・現在は未導入）:

- **mineru** 3.4.4（OCR本体。PyTorch 2.13 cu130 が RTX 5060 Ti を認識することを確認済み）
- **img2pdf / pillow**（TIF → OCR用可逆PDF生成）

環境依存の注意:

- GPU が Blackwell 世代のため、古い CUDA 前提のツール（例: ndlocr_cli の CUDA 11.1 世代 Docker）は動作しない可能性が高い
