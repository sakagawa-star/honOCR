## 対応

指摘（高・1件）を反映した。**Claude Code の設計判断の誤り**であり、指摘は正確である。

当初の設計では「`{NORM}` は `apply_fixes.py` が冪等なので復元しない。不整合は手順0 の
`md bytes identical` で検出できる」と書いていたが、手順0 は同一でなければ**中断する**仕様のため、
検出できても次回の実行が必ず止まり、再開不能な状態が残る。「検出できる」ことを利点のように
記述したのが誤りであった。

修正内容:

- 復元手順に「**`{NORM}` の md も退避から復元する**」を追加
- 復元後に `cmp` で `{NORM}` と `{FINAL}` がバイト同一に戻ったことを確認する手順を追加
  （`NORM_FINAL_IDENTICAL`）。あわせて「なんていいう」2件・54009 文字（＝手順0 の期待値）に
  戻っていることも確認する
- 「なぜ `{NORM}` も戻すのか」の理由（戻さないと手順0 で必ず中断して再開できない）を明記
- §9 のエラー表も同じ内容に整合させた
