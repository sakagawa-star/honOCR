## 対応

指摘（中・2件）を全件反映した。

1. **`{SCRATCH}` の定義と退避手順**: §6 冒頭に作業用ディレクトリの定義（絶対パス・作成方法・
   保存期間）を新設し、手順0 に `cp` による退避コマンドと成功確認（`sha256sum`・`diff -r`）を
   明記した。退避に失敗した場合は手順1 に進まず中断すると定めた
2. **`{FINAL}` の部分更新への対処**: `scripts/build_final.py` の実装を確認し、ファイル単位では
   原子的（一時ファイル → `os.replace` の `copy_atomic`）だが**ディレクトリ全体としては
   原子的でない**ことを確認した。手順0 で `{FINAL}` 全体を `cp -a` で退避し、
   手順3 に「失敗時の復元」節（リトライ禁止・退避からの復元・`diff -r` 確認・中断報告）を
   新設した。§9 のエラー表にも反映した
