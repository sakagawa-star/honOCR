#### 1. 数式部分の切り分け方法が未定義

比較規則は「`$…$` / `$$…$$` に囲まれた範囲」を数式部分としますが、原本の書き起こしは
見えたまま記録する手順であり、通常は `$` 区切りを持ちません。このままでは原本書き起こしの
どこを数式として D4 比較へ渡すかを実施者が判断することになります。

- **該当**: `requirements.md:151`、`design.md:496`、`design.md:512`
- **修正案**: 詳細記録の「原本の質問文」における数式範囲の表記規約を定めてください。
  例えば、原本上で数式組版となっている範囲を書き起こし時に `$...$` で明示し、
  その区切り記号自体は比較対象外とする、と明記します。
