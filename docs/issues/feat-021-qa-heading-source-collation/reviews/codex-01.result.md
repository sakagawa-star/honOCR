## 高

### 1. 判定区分の「複数記録可」と「区分別件数の合計 74」が両立しない

判定区分が「複数記録可」なのに、要約では M0〜M4 の件数合計を 74 と要求しており、両立しません。
1件が M1 と M2 の両方に該当すると明記されているため、区分別に集計すれば合計は74を超えます。

- **該当**: `requirements.md:124`、`requirements.md:154`、`design.md:502`
- **修正案**: 「主判定」は M0〜M4 の排他的な1区分として合計74にし、M1/M2/M3 を別途の複数選択フラグとして
  記録・集計する、または区分別件数の合計74という受け入れ基準を廃止して
  「判定済みユニーク件数」を74と定義してください。

## 中

### 2. M0 の定義（文字単位で同一）と、数式の LaTeX 表記差を M0 とする設計が矛盾する

M0 の定義は「文字単位で同一」ですが、設計は数式の LaTeX 表記差を意味が同じなら M0 としています。
質問文全文を文字単位で突合する要求と矛盾し、数式を含む見出しで結果が実施者依存になります。

- **該当**: `requirements.md:128`、`design.md:497`
- **修正案**: M0 を厳密一致に統一するか、許容する LaTeX 正規化規則を具体的に定義したうえで、
  要求側の M0 定義も「正規化後に一致」へ変更してください。

### 3. `--margin` の検証が NaN / inf を受理しうる

`--margin` は「0以上」としか検証しないため、NaN や inf を受理し得ます。後続の座標変換で例外となり、
検証完了後に処理が失敗するため、検証先行・出力なしの保証を崩します。

- **該当**: `design.md:338`、`design.md:344`
- **修正案**: `--margin` と bbox の全値について「bool 以外の有限数値」を必須条件とし、
  `math.isfinite()` による検証と NaN/inf のテストケースを追加してください。

### 4. 重複した `--index` を許容すると生成枚数が指定数と一致しない

重複した `--index` を許容すると、同一パスへ2回保存され、指定数に対して実ファイルは1枚しか生成されません。
FR-005 の「指定したブロックの枚数分の PNG」と整合しません。

- **該当**: `requirements.md:172`、`design.md:359`
- **修正案**: 重複 index を検証エラーにするか、重複を事前に除外して
  「ユニークな index ごとに1枚」と入出力仕様・生成件数を明記してください。
