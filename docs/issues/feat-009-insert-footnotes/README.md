# feat-009: MinerU 出力から欠落する脚注（訳注）の Markdown 挿入（insert_footnotes.py）

- **ステータス**: Closed（2026-08-25 完了。ユーザー手動テストで chap01 注釈4・5 の表示を確認）
- **種別**: feat（機能追加）

## 概要

MinerU は content_list.json に `page_footnote` 型として脚注（訳注）を出力するが、**Markdown（.md）には `page_footnote` 型ブロックを一切出力しない**。そのため最終成果物の Markdown から全脚注が欠落している（ユーザー報告 2026-08-25: chap01 式 (1.45) 後の注釈 4・5「訳注：データ集合を…」「訳注：頻度主義と…」が見当たらない）。

対処として、content_list.json の `page_footnote` ブロックをページ単位で組み立て、Markdown の該当ページ末尾位置に blockquote として挿入する後処理 CLI `scripts/insert_footnotes.py` を追加し、既存の最終成果物に適用する。あわせて `scripts/ocr_dir.py` の一括パイプラインに組み込み、今後の OCR 実行でも自動適用されるようにする。

## 調査記録（2026-08-25）

### 欠落の事実確認

- `{BASE}/ocr/final/chap*/*.md` を「訳注」で grep すると全章 0 件。一方 content_list.json には `page_footnote` ブロックが存在する
- 章別の `page_footnote` ブロック数（final の content_list 実測）: chap01 = 24、chap02 = 3、chap06 = 4、その他5章（chap00/03/04/05/07）= 0。計 31 ブロック
- 注釈 4・5 は `final/chap01/chap01_gray300_content_list.json` のインデックス 308・309（`page_idx: 41`）に全文が正しく OCR されている

### page_footnote ブロックの性質（chap01/02/06 全 31 ブロック実測）

1. **断片化**: 数式を含む脚注は複数ブロックに分割され、さらに本文の一部を重複して切り出した「浮遊断片」が混入する。例: chap01 p64 の訳注 10 は本体（idx 569）＋数式（571）＋続き「で定義される．」（570）＋浮遊断片「での t の」（568）の 4 ブロック。浮遊断片は同一ページ内の別脚注ブロックの部分文字列（空白を除去して比較）になっている
2. **並び順が読み順でない**: content_list 内の順序は bbox（`[x0, y0, x1, y1]`、0–1000 正規化、ページ左上原点）の読み順と一致しないことがある（例: p64 は 568→569→570→571 の順だが読み順は 569→571→570）。bbox の (y0, x0) 昇順ソートで読み順に復元できることを全ページで確認
3. **ページ跨ぎ**: 脚注 2（p30）の続きが p31 に番号なしブロック（idx 167「英語では圧倒的に joint が…」）として存在する。原本でも p31 下部に印刷されているため、ページ単位の挿入で位置は忠実になる（跨ぎ結合はしない）
4. **章境界**: chap01 の最終ページ（page_idx 83 = 第2章冒頭が写ったページ）の脚注 1 ブロックは、同ページの本文ブロックが chap01 の md に存在しないため挿入先アンカーがない。同じ脚注は chap02 の処理結果（page_idx 1）に存在するため、chap01 側はスキップで正しい

### 挿入位置決定の実現性（chap01 実測）

- content_list の text ブロック 480 件中 476 件が md に完全一致で出現（不一致 4 件 = page 83 の 3 件＋`&emsp;` 挿入で改変された 1 件）。equation は 157/157 件一致。画像は `img_path` の文字列が md の `![](images/…)` に出現
- 順方向カーソル付き検索（md 内の出現位置を単調増加で辿る）でブロック→md 位置の対応が取れ、各ページの「md に現れる最後のブロック」の直後の段落境界（`\n\n`）を挿入点にできる
- プロトタイプ実測（スクラッチパッドで検証、成果物には含めない）: 組み立て後の脚注は chap01 = 15 件（14 挿入＋p83 の 1 件アンカーなしスキップ）、chap02 = 3 件挿入、chap06 = 2 件挿入。式 (1.45) 後の注釈 4・5 が正しい位置・正しい順序で挿入されることを確認

### その他

- MinerU 3.4.4 に脚注を md に含めるオプションはない（`page_footnote` は md 生成対象外の型）
- content_list.json は MinerU スキーマ維持のため無改変とする（feat-008 と同方針）
- `final/chapNN/*.md` と `mineru-full/chapNN/run-01-normalized/*.md` はバイト同一（feat-008 で復旧・検証済み）。既存データへの適用は両方に行い、同一性を維持する
