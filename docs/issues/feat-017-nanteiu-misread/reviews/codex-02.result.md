## 対応

指摘（中・2件）を全件反映した。

1. **マニフェストの対象を全通常ファイル（再帰）に拡大**: `.md` / `.json` のみだったものを
   `rglob('*')` による全通常ファイル（`images/` を含む）に変更した。
   対象ファイル数は 33 → **541** になり、基準の集約ハッシュも採り直した
   （`AGGREGATE = 1fa3f0ca33d3f103f095cb9a20b64bd40e27775e616e7d1502ed1a227286ac72`）
2. **個別ハッシュの出力・保存**: `print(manifest, end='')` を追加し、パスと SHA-256 の一覧を
   `tee` で保存するようにした。照合手順も「実装後に `_after.txt` へ出力し、
   `diff` が無出力であること」に変更し、不一致時に変更ファイルを特定できるようにした
