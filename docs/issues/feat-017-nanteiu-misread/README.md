### 3.1 図 3.15・3.16 のキャプションについて（特に慎重を要した2件）

#3・#4 は「なん**と**いうことはない」が「たいしたことではない」の意の慣用句として
日本語に存在するため、機械的に誤読と決めつけられない。原本を確認したところ
**いずれも「なんていうことはない」**であった。

これは図の主旨とも整合する。図 3.15 は (左) 出た目の合計、(中) 合計 − 3.5n、(右) 合計/n の
3枚を並べ、**合計そのものは 3.5n に収束しない**（収束するのは 合計/n）ことを示している。
すなわち「合計が 3.5n に近づいていく、なんていうことはない」＝「そのようなことは起きない」
という否定の意味であり、「たいしたことではない」という慣用句ではない。図 3.16 も同じ構造である。

## 4. 検出の限界（本件が既存の警告に掛からない理由）

- 「と」「て」はいずれも JIS X 0208 内の文字であり、feat-011 の「JIS X 0208 外漢字の警告」に
  現れない
- 字形の 1 対 1 対応ではない**語彙単位の誤り**であり、feat-013 で21種に拡充した
  字形正規化テーブルでも扱えない（「なんという」は「なんという大事件だ」等で正当に使われる）
- feat-016 の「上的 → 上の」・feat-015 の「なんという → なんていう」（chap02 分）と同種であり、
  CLAUDE.md のドメイン知識に記載済みの既知の類型である。機械的な検出手段がなく、
  ユーザーの手動テストによってのみ発見された
