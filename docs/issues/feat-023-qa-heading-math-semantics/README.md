### 2.1 chap06 `? 6.3`（推定量のハットの消失）

| | 内容 |
|---|---|
| 原本 | `？6.3 あらゆる種目 $\theta$ ですべてのライバルを凌駕する全種目征覇なスーパーチャンピオンの推定量 $\hat{\theta}$ を探さないといけないわけですか。がんばって探してみますね。` |
| md（誤） | `## ? 6.3 あらゆる種目 θ ですべてのライバルを凌駕する全種目征覇なスーパーチャンピオンの推定量 θ を探さないといけないわけですか。がんばって探してみますね。` |
| 所在 | `{BASE2}/ocr/final/chap06/chap06_gray300.md` **253 行** |

**2つめの `θ` は原本ではハット付きの推定量 `θ̂` だが、md では素の `θ` になっている。**
統計学において θ（真のパラメータ）と θ̂（その推定量）は別物であり、**区別が消えると意味が変わる**。
この見出しは「あらゆる種目 θ に対して最良の推定量 θ̂ を探す」という質問であり、
ハットが失われると質問が成立しない。

あわせて、**2つの `θ` はいずれも数式マークアップ（`$…$`）が付いていない**。

### 2.2 chap08 `? 8.3`（太字ベクトル記法の消失）

| | 内容 |
|---|---|
| 原本 | `？8.3 第 $i$ 主成分が $z_{i}=\boldsymbol{q}_{i}\cdot\boldsymbol{x}$ で求められるのはなぜ？` |
| md（誤） | `## ? 8.3 第 i 主成分が $z_{i}=q_{i}\cdot x$ で求められるのはなぜ？` |
| 所在 | `{BASE2}/ocr/final/chap08/chap08_gray300.md` **285 行** |

**原本では `q_i` と `x` が太字（ベクトル）だが、md では素の `q_{i}`・`x` になっている。**
本書はベクトルを太字で表す記法を採っており、**太字が失われるとスカラーとの区別が消える**。
`z_i = q_i · x` は「ベクトル `q_i` とベクトル `x` の内積がスカラー `z_i`」という式であり、
太字の有無で式の意味が変わる。

あわせて、**「第 `i` 主成分」の `i` に数式マークアップが付いていない**（原本は `$i$`）。

## 3. 対象範囲（ユーザー決定 2026-09-06）

**対象の見出し2行を原本と完全一致させる。** すなわち、意味に影響する記号（ハット・太字）の復元に加え、
**同じ行にある平文の数式（chap06 の「種目 θ」・chap08 の「第 i」）も `$…$` にする。**

### 3.1 この決定の理由

- chap06 のハット復元には `$\hat{\theta}$` と書く必要があり、**数式マークアップの付与が不可避**である。
  「意味に影響する欠落だけ」を直すと、**同じ一文の中に平文の `θ` と数式の `$\hat{\theta}$` が混在**する
- 対象は2行のみであり、行単位で原本に一致させるほうが結果を検証しやすい

### 3.2 後続案件案 F への影響

feat-021 の後続案件案 **F**（インライン数式のマークアップ欠落。`D4` が立った全18件）のうち、
**本案件で 6.3 と 8.3 の2件が解消する**ため、**案 F の残件は 16 件になる**。
案 F を起票する際は件数を数え直すこと（本案件では案 F を起票しない）。
