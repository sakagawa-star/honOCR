### 式の連鎖（`CLAUDE.md`「ロードマップの改訂（再計画）」の「書いてよいもの」2）

**予想を生んだ式**: `判定結果レコード件数 = U_smoke = 1`（`roadmap.md` §8 の S2-1）。

**実測が式のどの項を決めたか**: `roadmap.md` §7 のステージ表で S2-1 の**決める項は「無し」**（手段の単体疎通）である。したがって本ステージの出力は、最終出力の式の入力項をどれも決めていない。実測が決めたのは、同ステージ表の**手段の欄**（「無し（新規の逆引き処理）」）に置いた逆引き処理が、**実行時の照合規則**（`design.md` §1.4.2 の改訂前の規則）の照合キーと `K` の階梯で候補 1 件からブロックを特定できなかったという事実である。

**最終出力の各変数への伝播**: ステージ表を前向きに辿ると、S3 の手段は「S2-1 で疎通した逆引き処理＋`scripts/crop_blocks.py`＋目視」、S4 の手段は「S2-1・S3 で疎通した手順」である。S3 の出力は `q`・`p₀`、S4 の出力は `k`・`u` であり、`k`・`u` は最終出力の式

```
M̂ = N × k / (n − u)
CI = [ N × Wilson(k, n).lo , N × Wilson(k + u, n).hi ]
```

の入力項である（`roadmap.md` §2.3）。したがって S2-1 の手段が疎通しない限り、`k`・`u` は得られず、`M̂`（次元 1）と `CI`（次元 2）は計算できない。`N` = 414（S2 で確定）は本ステージの実測の影響を受けない。
