## 経緯（人レビューの指摘と規定の改訂）

人（ユーザー）レビューで次の指摘があった: **想定値の式の入力に付けたラベル「調査時点の実測」が、`docs/REVIEW_CRITERIA.md` 1.11 項目3 の閉じた 3 種（前のステージの実測／測るステージの測る項／ロードマップで固定した定数）のどれでもない。** 値（98・414）は正しく §4.3 に出所もあるが、ラベルが検査に使えない。feat-024 では同じ「調査」というラベルで**推測**が式に入っていたため、このラベルを認めると推測と実測を区別できなくなる。

この指摘を受けて **CLAUDE.md と `docs/REVIEW_CRITERIA.md` 自体が update-014 で改訂された**:

- CLAUDE.md「想定値」: 入力値は 3 種のいずれかに限り**入力ごとにどれかを名指しする**。定数に**ロードマップ作成時の調査で数えた値**を含め、前提の表に典拠つきで置いて式から前提番号で参照する（**最初のステージのように前のステージが無い場合はこれを使う**）。3 種以外のラベルを作らない
- 1.11 項目3: 判定は**閉じた 3 種への該当**で行う。**出所が書かれていて辿れることだけでは適合としない**。3 種以外のラベルが付いた入力は、値が正しく出所が辿れても不適合

## 反映内容（4 箇所）

Codex の 15 回のレビュー（第1版 11 回・第2版 4 回）を通過していた記述である。「入力ごとに名指しする」は全ステージに掛かるため §8 を全件点検し、指摘された 2 箇所に加えて**同種の違反を 3 箇所**見つけて直した。

| # | 箇所 | 直す前 | 直した後 |
|---|---|---|---|
| 1 | S1・S2 | 「調査時点の実測 §4.3」 | 定数 `C_chap01` = 98（P13）・`C_all` = 414（P14）を前提の表に置き（いつ・何に・どの規則を当てて数えたかを典拠に記載）、式から前提番号で参照 |
| 2 | S2-1 | 「候補 1 件」 | 定数 `U_smoke` = 1（§7 で定めた処理単位）＋ **前のステージの実測**（S2 の候補レコードから 1 件） |
| 3 | S4 の `u`・`k` | 「`n` は上の式の値」 | `n` を `ceil(n₀/(1+n₀/N))` に展開し、入力を `N`〔S2 の実測〕・`q`・`p₀`〔S3 の測る項〕・定数の 3 種だけにした（読みやすさのため以降は `n` と書く旨を註記） |
| 4 | S5 | 「`n_eff` は上の式の値」「`p̂` は上の式の値」 | 中間量を展開し、`M̂`・`CI` を §2.3 の式のまま書いて入力を S2・S4 の実測と定数だけにした |

共通の原因は**同一ステージ内の先行する式の値**（`n`・`n_eff`・`p̂`）が 3 種のどれにも当たらないこと。式を展開すれば入力が 3 種に収まる。

あわせて §4.3 に残っていた「調査時点の実測」という語を、P13・P14 の典拠であることが分かる表現に改めた。

## Codex の判定

改訂後の 1.11 項目3 に照らして高・中の問題なし。

- S1・S2 の 98／414 は前提表の `C_chap01`（P13）・`C_all`（P14）へ典拠つき定数として移され、式から番号参照されている

- 旧ラベル「調査時点の実測」は想定値の入力から除去され、新たな第 4 種ラベルも無い
