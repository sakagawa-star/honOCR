## 対応（Claude Code 本体）

同種の取り残し（範囲を限定し忘れた「作らない」）を一度で潰すため、3 文書を「作らない・変えない・コードは・新規のコード・新しいスクリプト・追加しない」で全件走査し、範囲が限定されていない記述 4 か所をすべて修正した。

1. `requirements.md` §1.1: 「**S3 のステージの実行に使うコードは作らない・変えない**（C-301）。ただし…実験コード 2 本は C-309 に従って作る（S3 の実行では使わない）」
2. `design.md` §1.4.6: 「新しいスクリプトを作らない」→「S3 の実行のための新しいスクリプトを作らない。ADR-19」
3. `design.md` §1.9.1: 「コードを変更しないため」→「S3 の実行に使うコードを変更しないため。閾値実験の実験コードは `tests/` にテストを置かず `--selftest` で確認する〔ADR-22〕」
4. `design.md` §2.2: 「本マイルストーンで書くコードは無いため」→「S3 の実行のために書くコードは無いため…（閾値実験の実験コードの仕様は criteria.md に固定。ADR-22）」

走査で残った他の記述（`NFR-302` の「新しい外部パッケージを追加しない」、C-301・C-306・§1.2・§1.7・§2.3・ADR-19・ADR-22）は、いずれも既に範囲が限定済みか、依存の追加に関するもので実験コードとは矛盾しないことを確認した。
