## 残る指摘

### 1. 【高／前回1】「逆引き成功」と「判定可能」が区別されたまま、停止条件が片方しかない

`roadmap.md:156`

`r` はページを特定できた割合だが、`p₀` の分母は判定できた件数である。ページを特定できても全件判定不能なら、`r` > 0 のまま `p₀` が計算不能になる。また、本標本で `u` = `n` となる場合も、S5 の推定値と区間が計算不能である。

**修正案**: S3 の判定可能件数 0、S4 の `n_eff` = 0 を明示的な再計画条件にすること。`r` を有効標本数の予測に使うなら、ページ特定後の判定不能も反映する定義が必要。

### 2. 【中／前回2・変更に伴う問題】追加した上下界は、母集団総数の保証された上下界ではない

`roadmap.md:48`

`N×k/n` と `N×(k+u)/n` は、標本内の判定不能例を両極端に割り当てた推定値である。未抽出候補による標本誤差は含まない。例えば `u` = 0 なら両者は同じ値になり、全数調査でなくても「上下界」が一点になる。

**修正案**: 「判定不能例の割当てによる推定値の範囲」と明示し、母集団総数の上下界と区別すること。仮定なしの区間として報告するなら、標本誤差も含めた区間算出法を定めること。

### 3. 【高／前回4・変更に伴う問題】Wilson 区間の幅だけに有限母集団修正を掛けると、真値を必ず除外する場合がある

`roadmap.md:44`

記載式を計算すると、`N` = 414、`n_eff` = 78、`k` = 0 の区間は約 [0.952, 18.480] 件となり、0 件を含まない。母集団の欠落が実際に 0 件なら、どの標本でも `k` = 0 になるため、真値を常に除外する。`k` = 78 でも上限が約 413.048 件となり、414 件を除外する。

**修正案**: 幅だけを縮める式を撤回し、有限母集団の抽出設計に対応する区間推定式へ変更すること。真の欠落数 0 件・`N` 件と全数調査を境界例として検証する必要がある。

## 対応（全件反映済み。2026-09-09）

| # | 対応内容 |
|---|---|
| 1 | 指標を `r`（ページ特定率）から **`q`（判定可能率）** に一本化。`q` の定義に「ページを特定できなかった候補」と「ページは特定できたが判読できず判定できなかった候補」の両方を含めることを §7 と §8 の S3 に明記。停止条件を **S3: 判定できた件数 0（`q` = 0）** と **S4: `n_eff` = 0** の 2 つに分けて §8・M3・M4 に明記 |
| 2 | `M̂_low`・`M̂_high` を廃止。判定不能の両極端の割当てそれぞれに Wilson 区間を適用する定義（`CI_lo = N × Wilson(k, n).lo`、`CI_hi = N × Wilson(k+u, n).hi`、分母は全標本 `n`）に統合し、標本誤差と判定不能の両方を含む区間とした。点推定 `M̂` が仮定つきであることを §2.2 と M5 に明記。従属成分は 8 個 → 6 個 |
| 3 | **Wilson 区間への有限母集団修正を撤回**（素の Wilson を使用。区間は保守的に広くなる）。撤回の理由と、`N` = 414・`n` = 78 での境界例 4 通り（`k`=0 → [0.00, 19.43] が 0 を含む、`k`=78 → [394.57, 414.00] が 414 を含む、`u`=78 → [0, 414] で再計画条件、通常例）の実測を §2.2 に記載。標本サイズ算出側の有限母集団修正は残し、両者が矛盾しない理由を §8 の S4 に明記 |
