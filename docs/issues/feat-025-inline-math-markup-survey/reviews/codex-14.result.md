## 新規の指摘

### 1. 【中】Clopper–Pearson の非境界ケースの式が、未知数と確率を等置している

`roadmap.md:232`, `roadmap.md:234`

非境界ケースの式が、文字どおりには `lo = 確率 = α/2`（および `hi = 確率 = α/2`）となっており、未知数と確率を等置している。幅の計算そのものを定義する箇所なので、実装判断を残さない必要がある。

**修正案**: 「Σ… P(X = i | t, p = lo) = α/2 を満たす唯一の `lo`」「Σ… P(X = i | t, p = hi) = α/2 を満たす唯一の `hi`」のように書き換えること。

## 対応（反映済み。2026-09-09）

修正案のとおり書き換えた。`lo`・`hi` を「方程式 `Σ_{i=x}^{t} P(X = i | t, p) = α/2` を満たす唯一の `p`」という形で定義し、`x` = 0 ／ `x` = `t` の場合分けを先に置いた。あわせて**解の一意性の根拠**（左辺が `p` について狭義単調〔前者は増加、後者は減少〕であり、区間 [0, 1] の端で α/2 を挟むため解が一意に存在する）を明記し、数値解法（区間 [0, 1] の二分探索・反復 200 回）と分けて書いた。
