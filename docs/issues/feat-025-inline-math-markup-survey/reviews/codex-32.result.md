## 対応（Claude Code 本体）

`design.md` を次のとおり更新した（`requirements.md` は変更なし）。

- §1.4.5 の「全件処理」を 6 手順として定義（全件を先に検証 → 入力順に 1 件ずつ処理 → 章ごとに content_list を 1 回だけ読み再利用 → 解決に失敗したら部分結果を出さず終了コード 1 → 内訳を処理順に標準出力 → 全件終了後に入力順のまま原子的に書き出し）。逆引き失敗は異常ではなく終了コード 0 のままであることを明記
- **§1.4.8「候補 JSONL の読み込みと検証」を新設**。行番号は 1 始まり、空行は飛ばす、`RECORD_KEYS` との完全一致、キーごとの型と値域（`offset` は 0 以上の `int`、`char` はちょうど 1 文字、`chapter` は空でない）、5 種のエラーメッセージ（行番号つき）と終了コード 1・出力なし、最初のエラーで打ち切ってよいこと、境界条件を定義
- §1.1 対応要求マッピングの FR-203 の行に §1.4.5・§1.4.8 を追加
- §1.7 に `read_candidates` の振る舞い（検証と並び順の保持、例外→終了コード 1）を追加し、定数に `RECORD_KEYS` を追加。終了コード 1 の説明に「いずれも出力ファイルを作らない」を明記
- §1.8 の標準出力の行に、処理順＝入力順であることと `{行番号}` の意味を明記
- §1.9.1 に **T-125〜T-130** を追加（空行と並び順、5 種の検証エラー、行番号つきエラーで出力を作らない、2 章交互の入力順保持、途中の章の解決失敗で部分結果を残さない、逆引き失敗を含んでも終了コード 0）
- §2.2「実装判断ゼロの確認」に 3 項目を追加
