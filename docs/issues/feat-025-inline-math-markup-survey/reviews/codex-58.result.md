- **指摘 1（標本数）: 解消。** `n=19` は、各閾値が最大値または最小値という片側境界であることに対応しています。`criteria.md:136` の `1/(n+1)=5%` は、境界ごとの評価として妥当です。帯域は両端合計で 10% となる点も明記され、帯域外を `undecidable` とする扱いも固定されています。

## 対応（Claude Code 本体）

§2.4 を 6 段の手順として書き直した。

1. content_list のパスは M2-1 と同じ glob 規約（ちょうど 1 個）
2. **検索対象テキストは M2-1 `design.md` §1.4.3 の定義をそのまま使う**（`SEARCH_KEYS` 8 キーをこの順に、`str` はそのまま・`list` は `str` 要素を順に、`"\n"` で連結）
3. 照合キーは `before + math_text + after`。`before`・`after` は同じ行の中から取るため改行を含まない
4. 部分文字列として含むブロックを添字の昇順に集める。**正規化は一切行わない**（空白・改行・全角半角・Unicode 正規化のいずれも変換しない）。`K` の階梯による再試行も行わない
5. ちょうど 1 個なら採用、0 個・2 個以上は `特定不能`。同一ブロック内の複数出現は採用し、字形の対応は最初に現れる位置で行う
6. `crop_blocks.py`（既定の `--margin`）で切り出し、出力先を固定
