## 指摘

### 1. 【高】予備標本の結果によって本標本数が 0 件になる

`roadmap.md:139`

`p₀` = 0 または 1 では `n` = 0 となり、S5 の `p̂ = k/(n−u)` が計算不能。予備標本が全件判定不能の場合も、S3 で `p₀` を算出できない。

**修正案**: 端点でも成立する標本数の算定方法と、判定可能件数が 0 の場合の扱いをロードマップで固定すること。

### 2. 【高】判定不能例を除いた比率を母集団全体へ適用する根拠がない

`roadmap.md:151`

`N × k/(n−u)` は、判定不能例にも判定可能例と同じ欠落比率を当てはめている。しかし本書自身が、md と content_list の乖離が特定箇所に集中すると説明している。逆引き不能と欠落の有無が関連する場合、この推定は偏り、掲載する信頼区間にもその不確かさが入らない。

**修正案**: 判定不能例を解消する工程、または判定不能分を含めた推定範囲の式を定義し、最終出力へ反映すること。

### 3. 【中】予備標本の除外と、固定する推定式が整合していない

`roadmap.md:194`

本標本は予備標本 30 件を除いた集団から抽出するが、S5 は元の `N` に対する標本として扱っている。さらに `n` が予備標本の結果に依存するため、単純な固定標本数の無作為抽出と同一視できない。「統計処理上の扱い」を後続 design に委ねると、ロードマップで固定済みの式を変更する必要が生じる。

**修正案**: 本標本を全母集団から独立に抽出するか、予備標本と残余集団を区別した推定式・分散式を、この段階で定めること。

### 4. 【中】信頼区間が端点で幅 0 になる

`roadmap.md:151`

全数調査でなくても、`k` = 0 なら区間は [0,0]、`k` = `n_eff` なら [N,N] になる。未観測候補の不確かさを表現できない。少数の成功・失敗に対する正規近似の問題は NIST の説明にもある。

**修正案**: 採用する抽出設計に対応し、端点でも成立する区間推定法を固定すること。

### 5. 【中】S4 の外れ判定幅を計算できない入力がある

`roadmap.md:145`

予測値 `u = n(1−r)` を二項分布の試行数 `n−u` に代入しているが、これは一般に整数にならない。例えば `p₀` = 1/30、`r` = 29/30 では `n` = 13、`n−u` = 12.566…。また、幅の拡張に使う「95% 二項信頼区間」の算出法も未指定である。

**修正案**: 整数の試行数で成立する予測分布と、区間の算出・合成方法を明示し、criteria lock 時点で幅が一意に決まるようにすること。

### 6. 【中】新規手段の単体疎通ステージが不足している

`roadmap.md:106`

S3 は新規の逆引き処理を直ちに 30 件へ適用し、S5 も新規集計処理を直接使用している。CLAUDE.md「ステージの切り方の規則」が要求する、新規手段を 1 単位で通す先行ステージがない。

**修正案**: 新規手段ごとの単体疎通を先行ステージとして追加するか、使用する既存手段・手作業を明示してステージ表を整合させること。
