## 対応（Claude Code 本体）

**同じ指摘（判定規則の曖昧さ）の 2 回目である。** `CLAUDE.md`「行き詰まり検出」により、3 回目の試行には進まない。今回は「言葉で程度を書く」やり方を取り下げ、**すべての条件を 3 つの基準量との比だけで書く**形に改めた。

### 指摘 1（判定規則の閾値）

**基準量の節を新設**（§1.4.4 の「判定に使う基準量」）:

| 記号 | 定義 |
|---|---|
| `H` | 同じ行の和文（ひらがな・カタカナ・漢字）の外接矩形の高さ |
| `BL` | 同じ行の和文の外接矩形の下端を結んだ線（ベースライン） |
| `h` | 候補の字形の外接矩形の高さ |

**閾値は 0.8 / 1.2 / 1.5 / 0.2 の 4 つだけ**を使う。各項を次のとおり書き直した。

- **3-1 (a) 上付き**: 下端が `BL` より上、かつ高さ ≤ `0.8 × H` / **(b) 下付き**: 下端が `BL` より下、かつ高さ ≤ `0.8 × H`
- **3-1 (c) 分数**: 水平線の上下の両方に文字 / **(d) 根号**: `√` の横線が 1 文字以上を覆う / **(e) 範囲指定**: 3-2 の 6 文字の真上・真下・右上・右下に高さ ≤ `0.8 × H` の文字 / **(f) 行列**: 2 行以上を囲む括弧の高さ ≥ `1.5 × H`
- **3-2**: `h` ≥ `1.5 × H`
- **3-3 傾き**: **外接矩形の上端に接する画の位置が、下端に接する画の位置より右にある**（縦画が垂直なら当てはまらない）
- **3-4 隣接**: 隣接する字形の下端と候補の下端のずれが `0.2 × H` 以内
- **4 `not_missing`**: (i) `0.8 × H` ≤ `h` ≤ `1.2 × H` (ii) 下端と `BL` のずれが `0.2 × H` 以内 (iii) 3-3 の傾きに当てはまらない の 3 つをすべて満たす
- **確認できない場合**: `H`・`BL`・`h` を読み取れない、または閾値のどちら側か判断できない場合、その条件は**満たされないものとして次の項に進む**。結果として 4 の 3 条件を満たせなければ手順 5 で `undecidable`
- **同じ行に和文が無い場合**（別行立ての数式の中など）は `H`・`BL` が定まらないため、それらを使わない 3-1 の (c)・(d)・(f) と 3-3 だけで判定し、当てはまらなければ `undecidable` になることを明記
