## 指摘

### 1. 【高／codex-06 の 1 が未解消】`n_eff` < `m_req` の経路が塞がれていない

`roadmap.md:189`

`n = min(N, ceil(93/q))` は、実際の `n_eff = n − u` が 93 未満だった場合を扱っていない。`q` = 0.80 なら `n` = 117、期待値は 93.6 だが、実測 `n_eff` は 93 未満になり得る。そのとき Wilson 半幅は 0.10 を超えるが、停止・追加抽出・再計画の条件は `n_eff` = 0 のみである。また `q` < 93/`N` なら全数 `n` = `N` に打ち切っても期待有効標本数が 93 に届かない（`N` = 414・`q` = 0.20 で約 83 件）。精度要求を満たせない経路が残っている。

**修正案**: S4 に `n_eff` < 93 の停止条件を置き、追加抽出または再計画へ遷移させること。併せて `ceil(93/q)` > `N` を S3 または S4 の不成立・再計画条件にすること。

### 2. 【高／新規】要求対象の区間が成分にも S5 の出力にも無い

精度要求は「`p̂` の 95% Wilson 区間の半幅」とされているが、最終出力として定義・報告される区間は `Wilson(k, n)` と `Wilson(k+u, n)` である。`p̂ = k / n_eff` に対する `Wilson(k, n_eff)` は成分にも S5 の出力にも無い。したがって `n_eff` ≥ 93 を満たしても、要求対象の区間を計算・確認できない。

**修正案**: `Wilson(k, n_eff)` の区間を最終出力成分として追加し、その半幅を `e` の照合対象にするか、要求対象を現在報告する `[CI_lo, CI_hi]` に変更した上で、それに対応する達成可能な式・停止条件を定義すること。

## 対応（2026-09-09）

**両指摘とも、前提となる設計（`e` を最終出力への要求として維持する）を撤回したため、指摘の対象が消滅した。**

同じ論点（精度要求）で 2 往復したため `CLAUDE.md`「行き詰まり検出」が発動し、**「`e` = 0.10 を最終出力への要求として維持すべき」という推論を取り下げた**。`e` はユーザーの確定事項ではなく、Claude Code が `roadmap.md` を書く際に標本数を出すために置いた定数である。

その後の人（ユーザー）レビューで同じ論点が「`e` は最終出力への要求か、`n` を決めるための設計値か。要求なら S5 の式から S4 への条件（`u/n` の上限）が導出されるはずで、それが無いのは連鎖の切れ目。設計値なら、報告される区間の幅に要求が無いことを §1 か §2 に書くべき」と提起され、**設計値として確定**した（詳細は `roadmap.md` 改訂履歴「第1版（レビュー反映5）」）。
