## 対応（Claude Code 本体）

### 指摘 1（標本数の根拠）

`n_need` = 19 を維持し、根拠の記述を正した。§4.1 の各閾値は群の観測値の**最大値か最小値のどちらか一方（片端）**であり、次の 1 件がその片端を越える確率は `1/(n+1)`（端ごとに 5%）である。両端を使う帯 `T_band(G)` は端ごとに評価し、帯の外に出る確率の合計は 10% になるが、帯の外は `undecidable` に落ちるため `missing` / `not_missing` を誤って決める確率ではないことを明記した。Codex の「範囲外の確率は `2/(n+1)`」は両端をまとめて評価した場合の値であり、本書の閾値の使い方（片端ごと）とは評価の単位が異なる。この点を B で確認を求める。

### 指摘 2（G4 の扱い）

**G4 の判定規則を本書で事前に固定した**（§1.4）。あわせて §1.3 を新設し、対象文字集合のすべての文字を G1〜G4 のちょうど 1 つに割り当てた（数学記号 32 字 = G1 13 + G3 3 + G4 16）。G4 には大きさ・縦位置の比を使う条件を適用せず、構造の条件（3-1 の (c)〜(f)）と、隣接する上付き・下付き、ベースライン条件を外した 3-4 だけで `missing` を判定し、手順 4（`not_missing`）は適用しない。帰結として、G4 の候補（414 件中 37 件）は数式の要素と隣接していない限り `undecidable` になることも明記した。

### 指摘 3（抽出の定義）

§2.2 を実験コード `extract_samples.py` の仕様として書き直した。出力 `population.jsonl` の 8 キーのスキーマ、インライン数式の取り出し（`$$` で始まる一致を捨てる）、トークンの 5 種の定義（空白・制御語・制御記号・括弧・単一文字。`%` も単一文字）、添字の範囲（括弧の深さ・閉じ括弧が無い場合の扱い）、群への割り当ての条件（`SUP`・`SUB` は添字の先頭が英数字 1 文字かギリシャ文字の制御語のときだけ）、制御語と群の対応表、§2.4 の照合キー（`before + math_text + after`）、原本上の字形の対応（同じ字形の何番目か）を定めた。
