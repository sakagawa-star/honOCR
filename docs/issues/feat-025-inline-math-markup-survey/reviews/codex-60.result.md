## 対応（Claude Code 本体）

- **高 1**: §0「S3 との関係」を新設。本検証は S3 のステージの実行とは別の実験であり、出力は閾値の数値だけ、S3 の実行は本検証のコードを一切使わないこと、本検証のコードは実験コードであって S3 の手段に加わらないため単体疎通を要しないこと、`design.md` §1.2・ADR-19 の「作らない」は S3 の実行に使うコードについての記述でありその範囲の明示は本検証後の `design.md` 改訂で行うこと、標本は S3 とは別の母集団で S3 の測定に用いないことを明記
- **高 2**: 本検証の実験ログを `m3-pilot-measure/experiments/thresholds/experiment_log.md` と絶対的に定め、`CLAUDE.md`「実験・検証の進め方」の例示（criteria と同じ実験フォルダ）に沿うこと、S3 のログ `m3-pilot-measure/experiment_log.md` とは別ファイルであり本検証の記録を書かないこと、S3 のログには参照だけを書くことを明記。冒頭に「本フォルダ」の定義を追加
- **中 1**: `n_need` = 19 を「**運用上、事前に固定する標本数**であり統計的な保証ではない」と定義し直した。目安として、交換可能な 20 件（非復元抽出でも成り立つ）のうち 1 件が他の 19 件の最大値を**厳密に上回る**確率は 1/20 以下（同値があればさらに小さい）であることを参照し、この性質は本検証の母集団についてのもので S3・S4 の候補について保証するものではないと明記
- **中 2**: §3.2 に「成分の選択規則」6 項を新設（面積 4 画素以下の成分は雑音として除外／標本・基準文字は構成する成分をすべて選ぶ／他の字とつながっていれば切り分けず測定失敗〔基準文字は選び直さない〕／かすれの扱い／選んだ成分の番号と外接矩形を記録）。失敗理由に `基準文字分離不能` を追加し、§5 の記録項目に成分番号を追加
- **中 3**: Q2 の対象画像を「Q1 で測定に成功した標本の PNG のうち同じ PNG を重複させないもの、SUP → SUB → G1 → G2 → G3 の順、群の中は Q1 を測った順、すべてを測り打ち切らない」と固定し、§4.3 の判定時点を「対象画像のすべてを測り終えた時点」に改めた
- **中 4**: §6 の反映先を「本書 §1.3・§1.4 を `design.md` §1.4.4 の中に小節を新設して反映」に改めた
