## 指摘

### 1. 【高】「`e` は最終出力に効いていない」が式の追跡と一致しない

`roadmap.md:13`, `roadmap.md:75`

精度要求そのものを撤回した点は明確である。しかし「`e` は最終出力に効いていない」という記述は式の追跡と一致しない。`e → n₀ → n → S4 の標本数 → n_eff / p̂ / M̂ / CI_lo / CI_hi` と繋がり、さらに `n` 自体も S5 で報告される最終出力成分である。したがって `e` は最終出力の値に影響する。

**修正案**: 「`e` は最終出力の受入基準ではないが、標本設計パラメータとして `n` および下流の推定値に影響する」と改めること。そのうえで「区間幅・精度には要求を置かない」とすれば、要求の逆伝播を求める対象ではなくなる。

## 対応（反映済み。2026-09-09）

修正案のとおり是正した。`e` を「設計定数（最終出力には効いていない）」から**「標本設計パラメータ（最終出力の受入基準ではないが、`n` を通じて下流の成分の値には影響する）」**に改め、§1・§2.2・§8 の S4 の 4 箇所の文言を統一した。§1 には「『効いていない』のではなく『合否の判定に使わない』という意味である——`e` から S4・S3 への停止条件は導出せず、実測の区間幅が `e` に対応する幅を超えても、それを理由に再計画へは入らない」と明記した。
