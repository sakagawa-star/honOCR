## 1. 概要

本書には Q&A 形式のコラムがあり、その見出しは原本では

> **［？アイコン］ 1.2 そんなにたくさん会場を用意しなくても 18 会場で十分なのでは？**

のように、**影付きの装飾された疑問符（以下「？アイコン」）＋ 通し番号 ＋ 質問文**という
体裁で組まれている。

MinerU の layout 解析はこの ？アイコンを**見出しテキストから切り離し、独立した画像ブロック
（`type: "image"`）として出力する**ことがある。その結果、Markdown 上に
`![](images/{64桁hex}.jpg)` という**アイコンだけを切り出した画像参照行**が現れる。

この現象が確率統計の final 全10章で **6章8件**発生している。
文字の認識誤りではなく**ブロック分割の問題**であるため、`normalize_punct.py` の各種警告
（旧字体警告・JIS X 0208 外漢字警告）にも `build_final.py` の3種類の機械検証にも現れず、
手動テストで見つけるほかない（feat-015 と同種。`docs/PROJECT_KNOWLEDGE.md` のドメイン知識参照）。

本案件は、この8件を修正定義ファイル（`apply_fixes.py`）で訂正する。

## 3. 調査方法

### 3.1 8件の網羅（検出）

`{BASE2}/ocr/final/chap00〜09/images/` の**全画像**（計421枚）の実寸を PIL で読み、
**幅・高さがともに 80px 以下**のものを抽出した。該当は**ちょうど8枚**で、
それがそのまま本案件の対象8件である。

判定に 80px を用いたのは、？アイコンと本書の他の画像との間に十分な開きがあるためである。
全421枚を長辺の昇順に並べると、**アイコン8枚の長辺は 40〜46 px**、
**9番目（アイコン以外で最小の画像）は 167 × 166 px** であり、
46px と 167px の間（約3.6倍の開き）に画像は1枚も存在しない。
すなわち 80px という閾値は**2群が明確に分離した区間の中に置かれており**、
値を 50〜160 px の範囲でどう動かしても抽出結果は同じ8枚になる。

抽出した8枚をすべて1枚に並べて目視し、8枚すべてが同一意匠の ？アイコンであることを確認した。

### 3.2 見出しとの対応づけ

md 上の行の隣接だけでは対応先を誤る。`content_list.json` は
**bbox 読み順でソートされている**ため、ページ下部にあるアイコンが md 上ではページ先頭に
配置されることがあるからである（下記 §3.3）。

そこで `content_list.json` の **bbox（0–1000 正規化座標・ページ左上原点）の y 座標**で
同一ページ内のブロックを突き合わせ、アイコンと**同じ行にある**見出しブロックを対応先とした。

### 3.3 起票時に「原本確認が必要」とされた3件について

引き継ぎノート `2026-08-31_1153.md` では、chap02（`## 答` の前）・chap03（`## 例題 3.8` の前）・
chap06（本文中）の3件を「対応先が不明で原本確認が必要」と記録していた。

bbox で照合した結果、**3件とも B 型**（見出しに「?」があり画像が重複）であった。
md 上で見出しから離れて見えたのは、**アイコンがページ下部／中程にあるのに
content_list の読み順ソートでページ先頭に移動していた**ためである。

| # | 章 | アイコンの bbox | 同一行にある見出しブロックの bbox | 対応先 |
|---|---|---|---|---|
| 2 | chap02 | `[100, 736, 125, 761]` | `[100, 739, 703, 764]` | `## ? 2.8 じゃあどうしても原因と結果の区別を…` |
| 4 | chap03 | `[150, 275, 176, 299]` | `[149, 275, 476, 300]` | `## ? 3.7 正規化の変換式が覚えられません。` |
| 8 | chap06 | `[76, 617, 107, 643]` | `[76, 621, 677, 646]` | `## ? 6.4 予備実験で最強だった手法を実戦へ投入したら…` |

いずれも y 座標がほぼ一致しており（差は最大4／1000）、同一行であることは明白である。
**「C型（原本確認が必要）」という区分は存在しない。**

### 3.4 原本 TIF による確認

8件すべてについて、原本 TIF の該当行（アイコンの bbox から算出した領域）を切り出して目視した。
**8件すべてで、見出しの先頭に ？アイコンが実在する**ことを確認した
（アイコンに続いて `1.2` `2.6` `2.8` `3.7` `4.4` `5.1` `5.2` `6.4` の番号が並ぶ）。

すなわち、A 型3件は**原本にあるアイコンが md から失われている**（欠落）、
B 型5件は**原本にある1個のアイコンが md では文字と画像に二重化している**（重複）。

## 4. 既存の正常な Q&A 見出しとの関係

確率統計 final 全10章の md にある Q&A コラム見出しは、対象8件を含めて**計55件**である。

| 表記 | 件数 | 備考 |
|---|---|---|
| `## ? N.M `（半角 `?` ＋ 半角空白） | 44 | 多数派。本案件の B 型5件を含む |
| `## ?N.M`（空白なし） | 8 | 表記ゆれ。本案件の対象外（スコープ外） |
| `## N.M `（`?` なし） | 3 | 本案件の A 型3件 |

A 型3件に補う表記は、**多数派の `## ? N.M`（半角 `?` ＋ 半角空白）**とする
（2026-09-02 ユーザー決定）。原本でもアイコンと番号の間に空きがあり、体裁とも整合する。

`## ?N.M`（空白なし）8件の表記ゆれは**本案件では扱わない**（2026-09-02 ユーザー決定）。
対象8件との重複はない。

## 6. 修正方針（2026-09-02 ユーザー決定）

1. **A 型3件**: 見出しに `? ` を補う（`## 1.2 …` → `## ? 1.2 …`）
2. **8件すべて**: アイコンだけを切り出した画像参照行を md から削除する
3. **`content_list.json` と `images/` の画像実体は無改変**とする（既存ポリシー踏襲）
4. 既存の正常な Q&A 見出しの表記ゆれ（`## ?N.M` 8件）は**スコープ外**

修正手段は、既存の修正定義ファイル6章分への追記（すべて追記。新規作成はない）と、
`apply_fixes.py`（feat-010）→ `build_final.py`（feat-012）の再適用である。
**リポジトリ内のコード変更はない見込み。**

詳細は `requirements.md` と `design.md` を参照。
