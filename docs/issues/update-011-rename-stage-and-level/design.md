## 6. 設計判断の記録

| # | 判断 | 理由 |
|---|---|---|
| 1 | 段 → ステージ | ユーザー決定（2026-09-08「手と段は変える」）。データパイプライン・CI の共通語 |
| 2 | 手 → 水準、手 1 → 式の変更、手 2 → 次元の変更 | ユーザー決定。番号ではなく内容で呼ぶことで、次元を変えるかどうか（波及の有無）が名前で分かる。「インターフェース変更」は採らない（次元は数式の次元そのものであり、インターフェースではない。ユーザー 2026-09-08） |
| 3 | 次元はそのまま | ユーザー「数式の次元、そのまま」 |

| 5 | 置換は行全体の完全一致で全量列挙し、規則の再適用は Sonnet に行わせない | 規則の適用順・保護語の判断を反映者に委ねると結果が変わりうる。全量を `old`/`new` で固定し、模擬置換との一致で検証する |
| 6 | 過去の案件文書は改名しない | 記録の改変になる。対応表を CHANGELOG と本書に残して読み替える |
| 7 | 測る段 → 測るステージ（「測定ステージ」にしない） | 新しい語を増やさない。規則 3 の機械適用の結果をそのまま採る |
