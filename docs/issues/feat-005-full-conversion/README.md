# feat-005: 全スキャンデータの本処理（ディレクトリ単位の高精度 OCR）

- **ステータス**: Closed（2026-08-21 完了。全8章の final 構築・ユーザー確認済み）
- **種別**: feat（機能追加）
- **フェーズ**: フェーズ4（全ページ処理 → Markdown 生成）

## 概要

feat-003（MinerU 試行）・feat-004（句読点正規化）で確立したパイプラインを、スキャン済みの全データ（chap00〜chap07 の8ディレクトリ、計396枚）に適用し、LLM 学習用の主成果物である「LaTeX 数式入り Markdown」を得る。

- **ゴールは、入力として渡された TIF ファイル群に対する高精度な OCR 結果そのもの**。ページの除外（白紙・重複スキャン）、章境界の再定義、並べ替えなどの編集的な加工は**一切行わない**（2026-08-18 ユーザー指示）
- 処理単位はスキャンディレクトリごと（1ディレクトリ = 1 PDF = 1 Markdown）。各ディレクトリの補正済み TIF 全数を辞書順で PDF 化し、MinerU で変換、句読点正規化を適用して final ディレクトリに集約する
