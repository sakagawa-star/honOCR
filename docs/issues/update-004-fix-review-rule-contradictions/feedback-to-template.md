## 2. 項目1【高】レビュー単位の同一性を定める1文（update-004 由来）

### 2.1 問題

テンプレートは update-008 で全文ゲート C の上限単位を「レビュー単位」に変更したが、
**レビュー単位の同一性を定義していない**。そのため、同じ文書一式を初回レビュー（A）に
指定し直せば「新しいレビュー単位」を名乗ることができ、**C を何度でも実施できてしまう**。
これは「同じ文書一式に『新しい目』を2回使わない」という1回ゲート型の趣旨を無効化する。

### 2.2 発見の経緯

honOCR update-004 の Codex 全文ゲート codex-02（2026-09-04、gpt-5.6-terra medium）が
重要度「**高**」として指摘した。指摘の全文は本フォルダの `reviews/codex-02.result.md` にある。

honOCR 側はユーザー決定（2026-09-04）により、1文を追加して対処した
（設計は本フォルダの `design.md` §8.1）。**テンプレート側には同じ穴が残っている。**

### 2.3 テンプレートで行う変更（1箇所）

対象: `DEV_TEMPLATE/template/CLAUDE.md` 198行目（「収束」の定義の3段落目）

**置換前**（部分文字列。2026-09-05 時点で1回だけ存在することを確認済み）:

```
criteria 文書ごとに1単位とする。新しいレビュー単位のレビューは
```

**置換後**:

```
criteria 文書ごとに1単位とする。同一の文書一式は、指摘を反映して内容を修正した後も同一のレビュー単位である（同じ一式を A に指定し直すこと・分割し直すこと・ストリームを変えることによって新しいレビュー単位にはならない）。新しいレビュー単位のレビューは
```

反映後、テンプレートの 198行目は honOCR の `CLAUDE.md` 194行目と完全一致する（検証手段は §6）。

## 4. 項目3【低〜中】`README.md` にローカルの実パスを書かない（update-004 由来ではない）

### 4.1 問題

honOCR の feat フロー・bug フローのステップ8（完了）の末尾には次の一文があるが、
**テンプレートには無い**。

```
**`README.md` にはローカルの実パスを書かない**（公開リポジトリのため。`/home/...` 等の実パスは `{BASE}` などの抽象表現に置き換える）
```

### 4.2 経緯

honOCR が commit `01976ca`（README.md を追加し、CLAUDE.md に README 運用ルール（実パス禁止）を追記）で
独自に追加し、未還元のままになっている。**update-004 とは無関係の、以前からの乖離**である。

### 4.3 テンプレートで行う変更（2箇所）と、条件付きにする必要

honOCR の文面は理由を「公開リポジトリのため」と断定している。テンプレートは公開・非公開の
どちらのプロジェクトにも使われるため、**そのまま転記せず条件付きにする**こと。

対象: `DEV_TEMPLATE/template/CLAUDE.md` 64行目（feat フロー ステップ8）と 77行目（bug フロー ステップ8）。
両行とも次の文字列で終わっている（2026-09-05 時点で計2回存在することを確認済み）:

```
`README.md` に記載済みの内容（コマンド、CLIオプション、入力/出力形式、既定値、実行環境・依存条件）に変更があった場合は `README.md` を最新に更新する
```

**追記案**（上記の末尾に続ける。文面はテンプレート側で調整してよい）:

```
。**リポジトリを公開する場合、`README.md` にはローカルの実パスを書かない**（`/home/...` 等の実パスは `{BASE}` などの抽象表現に置き換える）
```

2箇所とも同じ変更を行う（feat フローと bug フローで規定を食い違わせない）。

## 5. 還元対象外と判断したもの

| 対象 | 判断 | 理由 |
|---|---|---|
| `CLAUDE.md` の他の差分 | 対象外 | すべて `{{ }}` プレースホルダ部分（プロジェクト概要・目標・背景・技術スタック節の言い回し・ドメイン知識の例示・ストリーム命名の略称・テスト実行コマンド・コーディング規約）。テンプレート側が意図的に穴埋め形式にしている箇所 |
| `.gitignore` の差分 | 対象外 | honOCR 側の追加は Python/uv（`.venv/`・`__pycache__/`・`*.pyc`）と OCR 成果物（`output/`）のみで、いずれも言語・ドメイン依存。テンプレートの `.gitignore` は `.claude/settings.local.json` と `.claude/handovers/` だけの言語非依存な最小構成を意図している |
| honOCR の `docs/PROJECT_KNOWLEDGE.md` の内容 | 対象外 | プロジェクト固有の知識（データの所在・MinerU の挙動・OCR 誤りの類型等） |
