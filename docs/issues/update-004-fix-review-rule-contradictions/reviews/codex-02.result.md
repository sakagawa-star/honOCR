## 回答（全文）

> [AGENTS.md適用]
>
> **高: 「レビュー単位」の同一性が規定されておらず、1回ゲート型を迂回できます。**
>
> README.md §2.4（60–74行）と design.md §3.1 の新文は、A で指定した文書一式を単位とするだけで、同じ一式を再度 A に指定して「新しいレビュー単位」としてはならないことを明文化していません。これでは同一の requirements/design や criteria を再登録して C を何度でも実施でき、明記された「同じ文書一式に新しい目を2回使わない」という目的と矛盾します。
>
