### 2.1 効いた規定（証拠）

- **段の表と「決める項」**: 判断の境界（逆引きの検証）が置かれず、段2（手段の単体疎通）は「決める項＝無し」として分布の検定等を積まなかった（11:29 Opus「規定に従って分布の検定は行いません」）
- **想定値と外れの幅**: 層G の想定外れ（k_G = n'_G）で中断・報告が機械的に起きた
- **梯子**: 第3版に至る経路が手1→手3 と記録され（`roadmap.md` §11.2）、層G の外れでは手4 に上がる前にユーザーの判断を仰いだ
- **予測記録のコミット**（運用）: M3 以降、予測の不改変が git で追える

### 2.2 ユーザーの介入で初めて決まった判断（規定化の優先度が高い）

- F5（外れの 2 型の区別。目標変更の根拠にしてよい外れとそうでない外れ）
