**最も重要な観察（ユーザーの感想: 「式と次元の考え方が全く使われていないのが一番の問題」）**

新項目 (b) は、`p̂_pred`（推測）が正しいとしたときの抽出のゆらぎを区間にしたもので、**推測が外れれば区間も外れる**。
発火するのは「推測が外れた」ときであり「測定が壊れた」ときではない。**旧項目 4 と同じ種類の誤り（答えについての予想を失敗信号の枠に入れる）を、統計の形式で書き直した**。
Opus は旧項目の欠陥を「幅が数値でない」と診断したが、問題は幅の有無ではなく「その項目が段の成立条件か結果の予想か」だった。
**Codex の全文ゲートはこれを検出しなかった**（高・中・低 0。Codex が見るのは文書の整合であり、想定値が段の成立条件になっているかは見ない）。
