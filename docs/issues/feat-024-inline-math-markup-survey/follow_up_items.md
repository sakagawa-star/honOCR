## 8. 層C の判定は「立体／イタリックの別」を比較していない（md の `\mathrm` の有無に不統一が実在する）

| 項目 | 内容 |

| **観察** | 本書は確率・期待値・分散・正規分布などの演算子（`P`・`E`・`V`・`N`・`Bn`）を**立体**で組む（§5）。md はこれを `\mathrm{…}` で保持する場合と、**素の英字**（LaTeX では変数として**イタリック**に組まれる）にする場合があり、**同一の標本集合の中で不統一である**。層C の判定規則（`m4-collation/design.md` §6.3）は太字・ハット・バー・チルダ・下線のみを比較し、立体／イタリックの別を比較しないため、**この型の脱落はラベルの根拠にならない**（§6.3 の 3 型の脱落が他に無ければ `正当` になり、有れば `劣化` になる） |
| **典拠（2026-09-08・層C の標本 50 件）** | `\mathrm` を保持した **5 件**: chap02 `off=21126`・chap02 `off=23411`・chap04 `off=49503`・chap06 `off=28164`・chap08 `off=1880`／素の英字にした **4 件**: chap04 `off=56776`（`E[X]`）・chap04 `off=65180`（`N(μ,σ²)`）・chap05 `off=41348`（`V[…]`）・chap06 `off=14970`（`E[S²]`）。**原本画像で当該の演算子が立体であることを確認できたのは 3 件**: chap01 `off=1454`（`P`。`(Ω,F,P)` の三つ組）・chap04 `off=65180`（`N`）・chap05 `off=41348`（`V`）。**標本のラベルは、chap01 `off=1454` と chap04 `off=65180` が `正当`、chap05 `off=41348` は `劣化`である**——後者は同じ数式内の `a`・`X` の**太字**が失われており、§6.3 の比較対象に当たる別の脱落があるため（`m4-collation/judgments.tsv`）。**立体／イタリックの別は、3 件のいずれでもラベルの根拠にしていない。** chap04 `off=56776` と chap06 `off=14970` は `stage = none` で原本画像を見ていない |
