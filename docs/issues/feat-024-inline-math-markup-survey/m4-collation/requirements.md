- **前のマイルストーン**: M3（層別標本抽出と原本ページの逆引き。2026-09-08 完了。標本 150 件・逆引き成功 136 件）

## 1.1 プロジェクト概要

- **何を作るのか**: M3 の標本 150 件について、原本ページの該当領域を切り出し、**目視で欠落・劣化の有無を判定**して、
  層ごとの `k_i`（欠落・劣化と判定された件数）と `n'_i`（有効標本数）を得る
- **なぜ作るのか**: **`k_i` と `n'_i` は最終出力の独立成分 6 個のすべてであり、本段はそれを生む唯一の段である**
  （`../roadmap.md` §1.2・§5）。段5 はこの計数から率と区間を算術で求めるだけである
- **誰が使うのか**: 段5（推定と報告）
- **どこで使うのか**: 本リポジトリの uv 環境（切り出し）と、Claude Code による画像の目視（判定）

**新規の実装は無い**（切り出しは既存 `scripts/crop_blocks.py`、判定は手作業。`design.md` §1.2）。

## 1.2 用語定義

`../roadmap.md` §1.2、`../survey_notes.md` §2、`../m3-sampling/requirements.md` §1.2 の用語を継承する。本書で新たに使うもののみ挙げる。

| 用語 | 定義 |
|---|---|
| **切り出し画像** | 原本 TIF から `crop_blocks.py` で切り出したグレースケール PNG（1 標本につき 1 枚） |
| **判定** | 切り出し画像と md の当該箇所を比較し、下記 4 値のラベルを 1 つ付けること |
| **`欠落`** | 層G・層L のラベル。原本では**数式組版**（イタリック体等）である記号が、md では数式マークアップの外にある状態 |
| **`劣化`** | 層C のラベル。md では `$…$` の内側にあるが、**原本の書体情報**（太字＝ベクトル、ハット、上下線）が失われている状態 |
| **`正当`** | 原本の組版と md の表現が一致しており、欠落・劣化のいずれでもない状態 |
| **`判定不能`** | 原本の該当箇所を確認できず、上記 3 値のいずれとも決められない状態（理由コードを付ける） |
| **`k_i`** | 層 `i` の標本のうち、`欠落`（層G・層L）または `劣化`（層C）と判定された件数 |
| **`n'_i`** | 層 `i` の有効標本数 ＝ 50 − `判定不能` の件数 |

## 1.3 機能要求一覧

### FR-M4-001: 原本ページの切り出し（Must）

- **機能名**: 逆引きに成功した標本について、原本の該当領域を PNG に切り出す
- **概要**: M3 の逆引き結果 TSV を入力に、既存 `crop_blocks.py` で切り出す。`stage = block` はブロックの領域、`stage = page` はページ全体を対象とする。**既存スクリプトを変更しない**
- **入力**: M3 の逆引き結果 TSV（3 ファイル）、content_list（`bbox`・`page_idx`）、原本 TIF
- **出力**: 切り出し画像（`{BASE2}/ocr/collation/` 配下。書籍本文を含むためリポジトリ外）
- **受け入れ基準**:
  1. `stage` が `block` または `page` の **136 標本すべて**が、存在する切り出し画像を参照できること
     （**標本と画像の対応は多対 1**。同じブロック・同じページの標本は同じ画像を共有する。`design.md` ADR-M4-6）
  2. `block/` と `page/` の画像が**互いに上書きされない**こと（別ディレクトリに出力する。`design.md` ADR-M4-2）
  3. `stage = none` の 14 件については切り出しを行わないこと（原本ページが特定できていないため）
  4. `crop_blocks.py` を変更していないこと（`git diff` が空であること）
  5. 生成率が `../roadmap.md` §6 の段4 の想定値と照合され `experiment_log.md` に記録されていること

### FR-M4-002: 突合（判定）（Must）

- **機能名**: 標本 150 件のすべてにラベルを付ける
- **概要**: 切り出し画像と md の当該箇所を比較し、`design.md` §6 の判定規則に従って 4 値（`欠落` / `劣化` / `正当` / `判定不能`）のいずれかを付ける
- **入力**: 切り出し画像、M3 の逆引き結果 TSV（`context` 列を含む）、成果物 md
- **出力**: 判定 TSV（**全 150 標本を収める単一ファイル**。層ごとに 50 行を追記する。書籍本文を含まない。リポジトリ内）と、詳細記録（書籍本文を含む。`{BASE2}` 配下）
- **受け入れ基準**:
  1. **標本 150 件のすべてにラベルが付き、未判定が 0 件**であること。かつ判定 TSV の識別子
     `(chapter, offset, kind)` が **M3 の標本 150 件と集合として一致**すること（欠落・余剰・重複が 0 件。層ごとに 50 件）
  2. `stage = none` の 14 件が**すべて `判定不能`（理由コード `no_page`）**であること
  3. `判定不能` のすべての件に理由コード（`design.md` §6.4 の **5 種**）が付いていること
  4. 層ごとの `k_i`・`n'_i`・`判定不能` 件数が算出され記録されていること
  5. 判定 TSV に書籍本文（`symbol`・`context` の値）が含まれないこと
  6. 詳細記録が `{BASE2}/ocr/collation/` 配下にあり、リポジトリに置かれていないこと

### FR-M4-003: 想定値との照合（Must）

- **機能名**: `../roadmap.md` §6 の段4 の 4 項目について、予測と実測を照合する
- **概要**: 切り出しの生成率・判定不能率（層ごと）・有効標本数・各層の判定の内訳（`0 < k_i < n'_i`）を照合する
- **入力**: 判定 TSV、`../roadmap.md` §6
- **出力**: `experiment_log.md` の予測・実測・照合
- **受け入れ基準**:
  1. 4 項目すべてについて実測が記録され、`../roadmap.md` §6 の想定値と外れの幅に照らして判定されていること
  2. **幅を外れた項目がある場合は、微修正で押し通さず中断し、`CLAUDE.md`「ロードマップの改訂（再計画）」の梯子に従うこと**（`design.md` §8）

### FR-M4-004: 予測の記録（Must）

- **機能名**: 実行単位ごとに、その実行の直前に予測を記録する
- **概要**: `../m2-1-means-smoke/experiment_log.md` の**是正4〜7** に従う。**実行単位は 1 層**（切り出しと判定を含む）とし、
  その層の**切り出しを始める前**に予測を記録し、**その時点でコミット**する
- **入力**: `../roadmap.md` §6 の段4 の想定する項目
- **出力**: `experiment_log.md` の層ごとの予測節と、その時点の git コミット
- **受け入れ基準**:
  1. **3 層それぞれについて、予測 → 実行 → 照合の順で記録されていること**（3 層分の予測をまとめて先に書かないこと）
  2. 各層の予測が、**当該層の切り出しより前**にコミットされていること（コミットのハッシュが `experiment_log.md` に記録されていること）
  3. 予測項目が `../roadmap.md` §6 の段4 の想定する項目の枠の中にあること。枠の外の量を書く場合は「参考（判定に使わない）」と明示されていること
  4. **案件状態が実態に遅れずに更新されていること**（是正7）。4 時点それぞれで `design.md` 手順 A-6 の表のとおりに更新・確認されていること

## 1.5 制約条件

1. **新規の実装を行わない。** 切り出しは既存 `crop_blocks.py`、判定は手作業である。実装が必要と判明したら**中断して報告する**
2. 新規ライブラリを追加しない
3. **判定の対象・標本を入れ替えない**（M3 で確定した 150 件をそのまま扱う）
4. **判定規則を実測の途中で変えない**（`design.md` §6 に事前に固定する。変える必要が生じたら中断する）
5. 本書に**判定の閾値を書かない**（`../roadmap.md` §6 を参照する）
