## 1.1 プロジェクト概要

- **何を作るのか**: 段3・段5 が使う 3 つの手段を、**それぞれ 1 単位の入力で通す**（単体疎通）。
  対象は (a) 層別標本抽出スクリプト（新規）、(b) 既存 `locate_candidates.py` の `--input-sample` モード（実装済み・**未実行**）、
  (c) 推定スクリプト（新規）の 3 つである
- **なぜ作るのか**: `CLAUDE.md`「パイプラインの切り方」の規則
  「手段が『無し』の作業は、それを 1 単位の入力で通す単体疎通を 1 段にし、その手段を使う段より前に置く」に従うため。
  段3（150 件の抽出と逆引き）・段5（推定と報告）に入る前に、手段が動くことを確かめる
- **誰が使うのか**: 本案件の実施者（Claude Code）。成果物は段3・段5 で再利用する
- **どこで使うのか**: 本リポジトリの uv 環境（`uv run`）。GPU を使わない。ネットワークを使わない

**本マイルストーンは `roadmap.md` §5 の「決める項」が**無し**の段である。**
**疎通の確認以上の作業（性能測定・網羅的な異常系試験・追加の検証文書）を行わない。**

## 1.2 用語定義

本書・`design.md`・コード内で同じ用語を使う。`../roadmap.md` §1.2 と `../survey_notes.md` §2 の用語を継承する。

| 用語 | 定義 |
|---|---|
| **候補 TSV** | 段1（M1）が出力した候補の全量。`{BASE2}/ocr/collation/feat-024_candidates.tsv`（7 列・4,782 行＋ヘッダ） |
| **層** | `kind` 列の値。`G`（ギリシャ文字）/ `L`（日本語に挟まれた半角ラテン英字）/ `C`（インライン数式） |
| **母集団** | 候補 TSV のうち `location != table` の行（4,624 件） |
| **標本 TSV** | 母集団から抽出した行を、候補 TSV と**同じ 7 列**で書き出したもの |
| **逆引き** | 標本の各行について content_list のブロック（`block_index`）または原本ページ（`page_idx`）を特定すること |
| **有効標本数 `n'`** | 判定が付いた件数（判定不能を除く）。段4 が決める |
| **単体疎通** | 手段に 1 単位の入力を与えて実行し、所定の形式の出力が得られることを確認すること |

## 1.3 機能要求一覧

### FR-M2-1-001: 層別標本抽出スクリプトの単体疎通（Must）

- **機能名**: 母集団から層と件数とシードを指定して無作為抽出する
- **概要**: 候補 TSV を入力に、指定した層（`kind`）の母集団から、指定した件数を指定したシードで無作為抽出し、標本 TSV を出力する。段3 では同じスクリプトを 3 層に対して実行する
- **入力**: 候補 TSV のパス、層（`G` / `L` / `C`）、件数（正の整数）、乱数シード（整数）、出力先パス
- **出力**: 標本 TSV（候補 TSV と同じ 7 列・ヘッダ付き）。実行サマリを標準エラー出力に出す
- **受け入れ基準**:
  1. 層 `G`・件数 1・固定シードで実行し、**ヘッダ 1 行＋データ 1 行**の標本 TSV が出力されること
  2. 出力行の 7 列が、候補 TSV に存在する行と**完全に一致**すること（`chapter`・`offset` の組で候補 TSV に照合できること）
  3. 出力行の `kind` が `G`、`location` が `table` ではないこと
  4. 同じ引数での再実行の出力が**バイト一致**すること
  5. 件数が当該層の母集団サイズを超える指定では、出力を作らずに終了コード 1 で終わること

### FR-M2-1-002: 逆引きの `--input-sample` モードの単体疎通（Must）

- **機能名**: 既存 `locate_candidates.py` に標本 TSV を入力して逆引きする
- **概要**: FR-M2-1-001 が出力した標本 TSV を `--input-sample` に与えて実行し、逆引き結果の TSV を得る。**既存スクリプトを変更しない**
- **入力**: 候補 TSV、`{BASE2}/ocr/final`、標本 TSV、出力先パス
- **出力**: 逆引き結果 TSV（11 列。標本の 7 列 ＋ `stage`・`block_index`・`page_idx`・`reason`）
- **受け入れ基準**:
  1. **ヘッダ 1 行＋データ 1 行**の逆引き結果 TSV が出力されること
  2. 出力行の**先頭 7 列**（`chapter`・`line`・`offset`・`kind`・`location`・`symbol`・`context`）が、入力した標本 TSV のデータ行と**完全に一致**すること（別の候補行が出力されていないこと）
  3. `stage` 列が `block` / `page` / `none` のいずれかであること
  4. `stage` が `block` または `page` の場合、`page_idx` が 0 以上の整数であること
  5. 実行にあたり `locate_candidates.py` を**変更していない**こと（`git diff` が空であること）

### FR-M2-1-003: 推定スクリプトの単体疎通（Must）

- **機能名**: 層ごとの計数から母比率と信頼区間・推定件数を算出する
- **概要**: 層ごとの `(N, k, n')` を入力に、`p̂ = k/n'`、Wilson score interval（有限母集団修正込み）、推定件数とその区間を算出する。式は `../survey_notes.md` §9.1 に従う。段5 では同じスクリプトを 3 層に対して実行する
- **入力**: 計数 TSV（1 行＝ 1 層。`layer`・`population`・`k`・`n_eff`）、出力先パス
- **出力**: 推定結果 TSV（入力 4 列 ＋ `p_hat`・`ci_lo`・`ci_hi`・`est_count`・`est_lo`・`est_hi`）
- **受け入れ基準**:
  1. 1 層分（1 行）の入力に対し、**ヘッダ 1 行＋データ 1 行**の推定結果 TSV が出力されること
  2. 出力の 6 つの算出値が、**同じ入力に対する手計算値と一致**すること（一致の判定幅は `../roadmap.md` §6 の段2 の想定値による。手計算値は `design.md` §6.6 に示す）
  3. `n_eff` が 0 の行、`k > n_eff` の行、`n_eff > population` の行に対しては、出力を作らずに終了コード 1 で終わること
