## 予測の書き方の欠陥（本マイルストーンの記録）

### 何が起きたか

実行前に記録した予測に、**事前の幅（合否関数）を持たない点予測**が 3 つ混ざっていた。

| 項目 | 記録した予測値 | 実測 | 事前の幅 | 判定への寄与 |
|---|---|---|---|---|
| 手段1 `chapter` | `chap01`（確率 30.6%） | `chap03`（確率 14.1%） | **無し** | **無し** |
| 手段1 `location` | `body`（確率 85.9%） | `body` | **無し**（基準は `location != table`） | **無し** |
| 手段2 `stage` | `block`（確率 83.3%） | `block` | **無し**（基準は `stage ∈ {block, page, none}`） | **無し** |

これらは 1 件の抽出結果に対する確率変数の点予測であり、**どの値が出ても合否は変わらない**。
実測との差異を「確率的に正常な範囲」と述べることは、実測を見てから線を引く行為であり、
**事後解釈の禁止**（`CLAUDE.md`「実験・検証の進め方」手順4）に当たる。

### 判定に寄与した項目（幅を持つもの）

- `../roadmap.md` §6 の段2 の 2 項目（3 手段の疎通と、推定の出力の手計算値との一致。幅は同§6 による）
- `requirements.md` の受け入れ基準: 終了コード・行数・列数・`kind = G`・`location != table`・候補 TSV との一致・
  **先頭 7 列の完全一致**・`stage` の値域・`page_idx ≥ 0`・再実行のバイト一致・既存スクリプトの不変・境界 4 通りの終了コード 1 と出力なし

**これらはすべて一致しており、M2-1 の判定は変わらない。**

### 是正（以降のマイルストーンに適用する）

1. **実行直前の予測は、`../roadmap.md` §6 の当該段の想定する項目の枠の中だけに書く**
   （`CLAUDE.md`「実験・検証の進め方」手順2「予測する項目の枠は criteria 文書〔feat 案件では `roadmap.md` の段の表〕に事前定義してよい。値はフェーズ直前に確定する」）
2. 枠の外の量を参考として書く場合は、**「参考（判定に使わない）」と明示する**。幅を後から足さない
3. 確率変数を予測するときは、**点ではなく事前の幅（区間・集合）で書く**。
   段3 の逆引き成功率と `footnote` 件数は `../roadmap.md` §6 で既にこの形になっている（値と幅は同§6 を参照する）
4. **予測は「実行単位ごとに、その実行の直前」に記録する。複数の実行の予測をまとめて先に書かない**
   （`CLAUDE.md`「実験・検証の進め方」手順2・`design.md` §8）。
   **依存の有無・実行が決定的かどうかを理由に一括記録を正当化しない**（本マイルストーンで犯した逸脱）
5. **上記4 を構造的に担保するため、段3 以降は「実装（コードの作成）」と「実行（実データの投入）」を分ける。**
   実装のサブエージェント委任では実データの実行を行わせず、**各実行の直前に Claude Code 本体が予測を記録してから、
   その 1 実行だけを行う**。各マイルストーンの `design.md` に、実行ステップごとの予測の記録を手順として明記する
6. **予測を記録した時点で、その実験ログを git にコミットする**（実行前の内容が改変されていないことを
   git 履歴で独立に検証できるようにする。`../reviews/codex-40.result.md` の高2）
7. **マイルストーンの状態（`README.md` のマイルストーン一覧・実施記録、`roadmap.md` の状態欄）は、
   人レビューの承認・実装・実行のたびに、その場で更新する。** 記録が遅れると、文書上は
   「未着手・人レビュー待ち」のまま実行済みの記録が存在する状態になり、手続き違反と区別できなくなる
   （本マイルストーンで実際に生じた。`../reviews/codex-40.result.md` の高3）

### 位置づけ

本件は**手段の欠陥ではなく、予測の記録の仕方（手続き）の欠陥**である。段2 の出力値・段3 への引き渡しには影響しない。
`CLAUDE.md`「行き詰まり検出」の対象（同じ指摘の再発・同じ原因での失敗が 2 回）にも、
`../roadmap.md` §6 の想定値の外れにも当たらない（外れた項目は無い）。
**ただし手続きの逸脱は解消されておらず、本マイルストーンの記録は「出力値は満たす／手順逸脱あり」として残る**（§「判定」）。
