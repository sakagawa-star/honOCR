## 新規指摘

### 高: No-Go 時に M4 が完了できず、枝番マイルストーンを開始できない（デッドロック）

有効標本数を満たすことが M4 の**完了条件**である一方、不足時には M4 の後へ `M4-1` を挿入するとしている。
しかし feat フローでは次のマイルストーンは前のマイルストーン完了後でなければ開始できず、
**不足時の M4 は完了できない**。そのため `M4-1` を開始する前提が満たせず停止する。

**修正案（codex）**: M4 の完了条件を「有効標本数を算出して Go/No-Go を記録する」に変更し、
充足は判断結果の Go 条件および M5 の開始条件に置く。
