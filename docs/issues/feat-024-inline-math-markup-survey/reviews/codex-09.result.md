## 新規指摘

### 高: 完了条件(3) と判断分岐の条件が食い違う

完了条件(3) は有効標本数との比較結果を Go/No-Go として記録する一方、
判断分岐は**判定不能率だけで** Go/No-Go を決めている。
したがって「**判定不能率は上限以内だが有効標本数は不足**」という結果では、
M4 は Go と記録され得るのに M5 の開始条件を満たせず停止する。
前提12 は未検証であり M4 で確認するとしているため、この不一致を「起こらない」とは扱えない。

**修正案（codex）**: M4 の Go 条件を「判定不能率が上限以内、かつ有効標本数が必要数以上」と明記し、
有効標本数不足は M3 の標本設計不適合としてロードマップ改訂へ進む No-Go にする。

## 反映

Go 条件を (i) 判定不能率が上限以内 **かつ** (ii) 有効標本数が必要数以上 の連言にし、
No-Go を2種（(i) 不成立 = 突合手順・判定規則の欠陥 / (ii) 不成立 = M3 の標本設計の不適合）に分けた。
