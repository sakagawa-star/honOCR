## 新規指摘

### 高: 追加抽出が完了済み M3 の文書変更を前提にしている

「有効標本数不足時に M3 の標本設計を拡張する」は、**完了済み M3 の文書を変更する前提**である。
再計画規定では完了済みマイルストーンのフォルダ・記録は変更できないため、
この分岐が発生すると追加抽出を正規の工程として実施できない。

**修正案（codex）**: 不足時はロードマップを改訂し、既存 M3 を保持したまま
追加抽出用の新規マイルストーン（例: `M4-1`）を追加する行き先に変更する。

## 反映

M4 の分岐先を「完了済みの M3・M4 の文書と記録は変更せず、枝番マイルストーン（例: `M4-1`）を
M4 と M5 の間に挿入する提案」に変更。M5 の依存にも挿入時の扱いを追記。
