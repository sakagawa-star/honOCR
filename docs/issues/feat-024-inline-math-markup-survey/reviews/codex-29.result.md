## 結果（[AGENTS.md適用] マーカーあり）

### 高

1. **段4・段5・最終出力の計算関係が矛盾している**
   - `p̂_i` は `k_i / n'_i` であるにもかかわらず、段4 は `p̂_i`（＝`k_i`）と誤記し、段5 は `k_i` を入力に含めずに `p̂_i` を算出する記載になっている。このままでは Wilson 区間と推定件数を実装・再現できない
   - 該当: `roadmap.md:145`、`roadmap.md:146`
   - 修正案: 段4 の出力・決める項を `k_i` と `n'_i` に統一し、段5 の入力を `k_i, n'_i, N_i`、出力を `p̂_i = k_i/n'_i` と各従属成分にする。§1.2 の `k_i` の位置づけも同じデータフローに合わせる

2. **段4 の入力から content_list の `bbox` と `page_idx` が落ちている**
   - `crop_blocks.py` はこれらを使って切り出すが、段3 の出力は `block_index` / `page_idx` までで `bbox` を含まない。とくに `stage = page` は block index が未確定であり、ページから切り出し用 block を選ぶためにも content_list が必要である
   - 該当: `roadmap.md:145`、`roadmap.md:128`
   - 修正案: §4 の content_list 成分数に実際に使用する `bbox` 等を含め、段4 の「単位あたり入力」に対象 block の `bbox`・`page_idx`（またはそれを得る content_list）を明記する。`stage = page` の切り出し用 block 選択も段4 の入出力として定義する
