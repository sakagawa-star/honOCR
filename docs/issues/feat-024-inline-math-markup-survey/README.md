## 1. 概要

feat-021 が検出した `D4`（数式の不一致）18件のうち、feat-023 が意味に影響する2件を修正し、
**Q&A 見出し内の残件は 16 件**になった。しかし**本文（見出し以外）の同種の欠落は未調査**である
（feat-023 `design.md` §12-4 の引き渡し）。

本案件は、確率統計の全10章について「原本で数式として組まれている記号が md 上で数式マークアップを
失っている量」を、**機械的な候補抽出と標本抽出による母比率推定**で測定する。
**md の修正は行わない**（修正の要否はユーザーが本案件の報告を見て判断する）。

計画の内容は `roadmap.md` を、調査結果と実測値は `survey_notes.md` を参照する。
