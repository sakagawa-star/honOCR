すなわち原本の「**の**」が OCR で「**的**」として出力されている。誤認識であることが確定した。

## 4. 検出の限界（本件が既存の警告に掛からない理由）

- 「上」「的」はいずれも **JIS X 0208 内**の漢字であり、feat-011 の「JIS X 0208 外漢字の警告」には現れない
- 字形の 1 対 1 対応（例: 值→値）ではなく**語彙単位の誤り**であるため、feat-013 で21種に拡充した
  字形正規化テーブル（`normalize_punct.py`）でも扱えない
- したがって本件はユーザーの手動テストによってのみ発見された
