## 対応

高（未解消）を修正提案どおり**基準コピー＋ `diff -u` 方式**に書き換えた。

1. `design.md` §6 手順0: 変更対象4ファイル（`CLAUDE.md`・`docs/BACKLOG.md`・
   `docs/CHANGELOG.md`・案件 `README.md`）を `{BASE_COPY}` へコピーする規定に変更。
   `git status --short` の記録は「対象外パスの補助確認専用」に格下げし、
   内容の証明に使わないことを明記
2. §7.1 確認1・冒頭文: 内容検証を基準コピーとの `diff -u` に変更
   （確認2〜8 の `git diff CLAUDE.md` は、CLAUDE.md が基準時点で git 上変更なしのため維持）
3. §7.2 確認9〜12: すべて `diff -u {BASE_COPY}/... ` による内容検証へ変更。
   確認13 は補助確認（対象外パスの検出専用）と明示
4. あわせて確認11 の機械確認コマンドの検出漏れを修正: `^-[^-]` は削除行自身が
   `- ` で始まる箇条書きのとき `-- …` となり検出できないため、
   `grep -E '^-' | grep -vE '^--- '` に変更した（自主修正）

解消確認は codex-05（依頼B・同一会話）で行う。
