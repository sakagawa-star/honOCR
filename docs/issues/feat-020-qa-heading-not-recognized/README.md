## 3. 調査方法

### 3.1 Q&A 見出しの網羅的な走査

```bash
cd /home/sakagawa/work/確率統計/ocr/final
uv run python -c "
import re, glob
pat = re.compile(r'^(##\s+)?([？?][ 　]*)?([0-9A-C]+)\.([0-9]+)(?=[ 　])')
for p in sorted(glob.glob('chap*/chap*_gray300.md')):
    ch = p.split('/')[0]
    for i, line in enumerate(open(p, encoding='utf-8'), 1):
        line = line.rstrip(chr(10))
        m = pat.match(line)
        if m and m.group(2):
            kind = '見出し' if m.group(1) else '★本文段落'
            print(f'{ch} L{i} [{kind}] {m.group(3)}.{m.group(4)} | {line[:60]}')
"
```

`##` の有無と `?` の有無をいずれも省略可能にすることが要点である。

### 3.2 番号の連番の穴と、本文中の相互参照による裏づけ

各章の Q&A 番号を集めて連番の穴を探し、穴の番号について md 全文を検索する。
さらに**本文中の相互参照**（`？N.M` / `?N.M` の形で他の Q&A を指す記述）を集計すると、
**見出しが失われた Q&A が原本に実在することを裏づけられる**。

```bash
cd /home/sakagawa/work/確率統計/ocr/final
grep -ho '[？?][ 　]*[0-9A-C]\.[0-9]\+' chap0*/chap0*_gray300.md | sort | uniq -c
```

実際この方法で、`? 2.9` `? 4.6` `? 4.7` `? 4.8` `? 5.6` `? 8.6` などへの参照が本文に存在し、
これらの Q&A が実在することを確認した。

### 3.3 型δ の発見

型δ の2件は、番号で検索しても行頭にヒットしないため上記だけでは見つからない。
**連番の穴として残った番号を、行頭に限定せず全文検索する**ことで発見した。

```bash
grep -n '2\.5' chap02/chap02_gray300.md
grep -n '7\.3' chap07/chap07_gray300.md
```
