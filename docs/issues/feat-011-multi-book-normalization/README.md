### 3.1 判明した課題

#### 課題A: 句読点正規化が適用不可（本案件の主目的）

確率統計の原本は **「、」「。」** を用いる（PRML は「，」「．」）。パイロット出力の実測は
「、」241 件・「。」260 件・「，」0 件・「．」0 件。

現状の `ocr_dir.py` は `normalize_punct.py` を**無条件で**呼び、さらに `check_normalized` で
「差分は許可置換のみ」「残存『、。』ゼロ」を検査する。このまま確率統計に適用すると
**501 箇所の句読点が「，．」に置換され、原本と異なる出力になる**。

#### 課題B: 中国語字（簡体字・繁体字）の混入

MinerU の中文モデル由来とみられる字形の誤りがある。JIS X 0208 に含まれない漢字を
機械抽出（`str.encode("shift_jis")` の可否で判定）したところ、
**PRML の既存 final（chap00〜07 の Markdown）にも 14 件（7 字種）存在**することが判明した
（`值` 3・`变` 4・`单` 2・`对` 1・`徵` 1・`跺` 2・`濵` 1）。
これに JIS X 0208 内の繁体字「樣」2 件を加えると、下表のとおり計 16 件になる。

| 出力字 | 正しい字 | PRML final（md 8章） | 確率統計 chap07（md） | 種別 |
|---|---|---|---|---|
| 值 | 値 | 3 | 0 | 簡体字 |
| 变 | 変 | 4 | 1 | 簡体字 |
| 单 | 単 | 2 | 0 | 簡体字 |
| 对 | 対 | 1 | 0 | 簡体字 |
| 图 | 図 | 0 | 1 | 簡体字 |
| 换 | 換 | 0 | 1 | 簡体字 |
| 徵 | 徴 | 1 | 0 | 繁体字・異体字 |
| 樣 | 様 | 2 | 6 | 繁体字（JIS X 0208 内のため上記の機械抽出では出ない） |
| 濵 | 演 | 1 | 0 | **字形対応ではない OCR 誤認識**（「濵習」→「演習」） |
| 跺 | 疎 | 2 | 0 | **字形対応ではない OCR 誤認識**（「跺な解」→「疎な解」） |

実例:
- `## 2.1 二值变数`（PRML chap02） → 正: `## 2.1 二値変数`
- `## Box-Muller 变换`（確率統計 chap07） → 正: `## Box-Muller 変換`
- `▶ 图 7.4 格子点`（確率統計 chap07） → 正: `▶ 図 7.4 格子点`
- `## 一樣分布`（確率統計 chap07、6件） → 正: `## 一様分布`

前 8 字種は「中国語字 → 対応する日本語字」の 1 対 1 対応が確立しており、機械置換で安全に直せる。
一方「濵→演」「跺→疎」は字形の対応関係ではなく個別の誤認識であり、一般規則にできない
（= `apply_fixes.py` の修正定義ファイルで扱うべきもの）。

#### 課題C: 脚注の番号プレフィックスが `*N` 形式で結合精度が落ちる

確率統計の脚注は `*1` 形式（MinerU 出力上は `\*1` とエスケープされる）。
`insert_footnotes.py` の `NUM_PREFIX_RE`（`^(?:\d+|[⁰¹²³⁴⁵⁶⁷⁸⁹]+)\s`）に一致しないため、
組み立てが以下のように劣化した（実行自体は成功し 3 ページ・4 件を挿入）。

- p4: 独立した 2 つの脚注 `\*2 参考文献 [8] の…` と `$^{3}$ ただし精度という…` が
  **1 行に連結**された（`\*2` も `$^{3}$` もプレフィックス正規表現に一致しないため）
- p10: 断片 `[0,1) でなく (0,1]` が親脚注の**末尾に残留**した。
  親は `…範囲は $[0,1)$ でなく $(0,1]$ とすべきです。…` と数式化されているため、
  空白除去のみの比較では部分文字列判定が成立しない

なお p10 の他 6 断片（`$X_{1}$`・`$X_{1}=0$`・`?7.3(p.259)` 等）は現行ロジックで正しく除去できた。
